# Safety guardrails

**Authority:** Minecraft observations → validated local state → safety-gated planner → fixed behavior set. Model output isn't a command, tool call, script, server address, movement target, or authorization decision. Survival advice is a single index into the current, locally generated job list; targets and recipes are rechecked before interaction. Soul Guard separately validates sleep advice, rejecting extraneous fields and contradictory intentions. Local summaries cannot edit profile values.

**Game capabilities:** By default the bot does not mine or build. `AUTONOMY_ENABLED=true` enables bounded jobs in Survival in the Overworld. Work can remove eligible logs and exposed stone, coal or iron; use a workbench and furnace at coordinates where the bot placed them; and build in empty cells of fixed home and workshop blueprints. Block and terrain checks are heuristics, not claim or ownership checks. Use a test world or a designated area away from existing builds. No attacks, chest access, trading, arbitrary chat commands, or operator privileges. Pathfinder itself cannot break/place blocks to move. The fixed `/tell` operation sends replies to validated in-game player names. Routine activity yields to danger, and retreat is best-effort, not immunity.

**Operators:** `MC_ADMINS` is empty by default. Mutations and sensitive inspection use sender UUID mapped to the server's player roster, not parsed display text. Microsoft mode also requires verified signed player chat. A malicious server can misrepresent the world; offline servers cannot authenticate names at all. Treat offline mode as an isolated trusted-development setting. `!stop` pauses routine activity, not the emergency retreat.

**Chat:** Addressed chat and journal notes are length-limited, normalized, and screened for common toxic and unsafe content. Replies are schema-checked and screened again. No model can produce slash-command output or raw newline-separated commands. Filtering is intentionally conservative and is not comprehensive moderation. Operator goals are untrusted preferences passed only to the local survival advisor, not cloud instructions. Terrain images are sent only to the configured Ollama endpoint; keep it on loopback for on-device inference.

**Deployment:** Keep model keys exclusively in environment/secret storage. Keep the auth cache, `soul.md`, and logs private; the Markdown save can contain social history, journal notes, coarse locations and audit data. Cloud is opt-in, HTTPS-only, and sleep-only, with redirects disabled, bounded response sizes, retry on transient failures, and abortable requests. Use one bot process and one authorized world per save file.
